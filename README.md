# 錠剤・カプセル棚卸し

PMDA公開の添付文書にある製剤重量を使い、測定した正味重量から錠数・カプセル数を推定する静的サイトです。

上部の「漢方薬」タブでは、棚卸しCSVの漢方顆粒・細粒116品目について、包数から薬剤の合計gを計算します。CSVの先頭の「棚1」列が `zaiko-nasi` または `zaiko-nashi` の品目を除外し、YJコードが52で始まり、単位がgで、薬品名末尾に `H2.500` のような包装g数がある品目を採用しています。バラ製品、漢方錠・カプセルは包数換算に含めていません。印刷一覧は元CSVの行順（棚1の並び）で並べます。漢方薬の記録は錠剤・カプセルの記録と別にブラウザー内へ保存します。

## 使い方

1. 医薬品名、規格、メーカー、YJコードで検索します。ひらがな・カタカナ、全角・半角を区別せず部分一致します。
2. 測定重量をg単位で入力します。容器込みで量った場合は容器の重さも入力します。全角数字は半角に変換されます。
3. 推定数量を確認して一覧に追加します。同じ医薬品は印刷時に合計されます。
4. 「一覧を印刷」から棚卸し一覧を印刷します。記録は利用中のブラウザーのローカルストレージに保存されます。

重量が未登録の製品は、選択後に「実測した1錠・1カプセルの重量」をg単位で入力できます。測定重量と容器重量を入力して一覧に追加すると、実測の1個当たり重量も同じブラウザーに保存され、次回の選択時に再利用できます。異なる端末には同期されません。実測値を修正したい場合は入力欄を上書きして一覧に追加してください。「保存済みの実測重量を消去」から再利用をやめることもできます。以前に追加した数量は自動で再計算されず、印刷一覧にはそのとき使用した実測重量が記載されます。

数量は `round((測定重量 - 容器重量) / 登録または実測した1錠・1カプセル当たりの重量)` です。添付文書の質量が「約」の場合や実際の製剤に重量差がある場合、数量は推定値です。端数がある場合、個々の製剤を確認してください。

## データ

`drugs.json` は元のカセットリストと棚卸しCSVの `棚１=bara` の薬品名を照合して作成し、個人や処方に関する情報を含めていません。`bara` の112品目のうち74品目は既存データと重複し、38品目を追加しました。追加分の1錠当たりの重量はPMDA公開添付文書PDFの製剤の性状欄で確認しています。CSVにYJコードのない品目には `BARA` から始まる棚卸IDを付け、YJコードと区別しています。

`weightG` はgの数値で、`source` は確認できたPMDAの該当添付文書です。185.5mgなどは計算用に元の精度を保持し、表示も必要な場合は小数第4位まで示します。添付文書で重量を確認できていない行は `null` とし、実測重量を入力した場合のみ計算できます。表中の「約」は `approx` に保持しています。利用者から確認値として提供された7件は `status: user-provided` とし、PMDA出典を確認した値と区別しています（添付文書URLは未登録）。データの改訂時はPMDAの3.2「製剤の性状」にある「質量」「重量」「重さ」を確認してください。

## GitHub Pages

このリポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。`main` への更新で `.github/workflows/pages.yml` がサイトを公開します。公開URLは Actions のデプロイ結果と Settings → Pages に表示されます。

ローカルでの確認は `python -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。`file://` ではJSONの取得がブラウザーに遮断されることがあります。
